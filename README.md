A Node 22 standard-library program that writes one line — a dog's excuse after being caught eating the homework, 1–200 characters — to `/output/entry.txt` for make.fun's "The Dog Ate My Homework: Funniest Excuse" bounty.

> I ate the homework, then I ate the answer key too, so the teacher can't prove a single answer wrong. Technically, I aced it.

Why this line: it is the dog's own voice, caught in the act; the twist is dog logic (eat the answer key and nothing can be proven wrong); the dog is proud, not embarrassed; it stands alone with no setup; and it dodges the stock lines — no cat, no taste of paper, no "good boy".

## Run it

```sh
node main.ts
```
